# 🧪 **Lesson 3: Build a Weather App with JavaScript Mini-Project**

**Tags**: `#lesson` `#level2` `#javascript` `#weather`
**Goal**: Create a weather app using POJOs, helper functions, and Bootstrap cards.
**Level**: Beginner web development
**Tools**: VS Code, Git, web browser

---

## 📋 **Lesson Overview**

In this lesson, you'll build a complete weather app that displays weather information for multiple cities. You'll learn how to work with JavaScript objects, manipulate the DOM, and create a professional-looking interface using Bootstrap.

**What you'll build:**
- A weather app using POJOs (Plain Old JavaScript Objects)
- Bootstrap cards for weather display
- Helper function integration
- Multiple city weather pages
- Interactive button functionality (optional challenges)

---

## 🚀 **Lesson Steps**

### **Core Steps (Required):**
1. **[Step 1: Create the Repository](weather-app-lv1.md)** - Set up your Git repository and project structure
2. **[Step 2: Set Up Project Files](weather-app-lv2.md)** - Create the necessary files and include scripts
3. **[Step 3: Copy Weather Data](weather-app-lv3.md)** - Get weather data from previous lessons or download fresh data
4. **[Step 4: Create POJO in script.js](weather-app-lv4.md)** - Convert JSON data to JavaScript objects
5. **[Step 5: Build the Weather Card](weather-app-lv5.md)** - Create Bootstrap cards with span elements
6. **[Step 6: Display Weather Data](weather-app-lv6.md)** - Connect data to the user interface
7. **[Step 7: Create Multi-City Weather Pages](weather-app-lv7.md)** - Scale your app to multiple cities

### **Optional Challenges:**
8. **[Challenge Part 1: Add a Button](weather-app-lv8.md)** - Make weather data appear only after button clicks
9. **[Challenge Part 2: Second City Button](weather-app-lv9.md)** - Add a second city button to the same page
10. **[Challenge Part 3: Multiple City Buttons](weather-app-lv10.md)** - Scale to multiple city buttons

---

## 🎯 **Learning Objectives**

By the end of this lesson, you will be able to:
- Set up a complete web development project with proper file structure
- Work with JavaScript POJOs and access nested data properties
- Use Bootstrap to create professional-looking user interfaces
- Manipulate the DOM to display dynamic content
- Organize code across multiple files and pages
- Implement event handling for interactive features
- Scale a project from single functionality to multiple features
