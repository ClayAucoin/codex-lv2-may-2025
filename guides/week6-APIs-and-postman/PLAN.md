## 📅 Weekly Lesson Plan

**Mon**

* **Lesson 1:** Search Params and Forms

  * *Mini-Project 1: HTML Forms* (students build their first form that uses query strings)
* **Lesson 2:** Postman and Search Params

  * Explore how query strings look in Postman requests.

**Tues**

* **Lesson 3:** Postman and Code Generation

  * *Mini-Project 2: Start (Pokémon API)* — use Postman to generate fetch code.
* **Lesson 4:** Callbacks and The Network Tab

  * Learn about asynchronous flow and practice inspecting requests/responses in DevTools.

**Wed**

* **Lesson 5:** JS Objects and Adding to the DOM

  * *Mini-Project 2: Continue* (use fake Pokémon data to create JS objects and render them).

**Thur**

* **Lesson 6:** JS Promises, `.then()`, and Function Parameters in Callbacks

  * Understand how to handle async API calls with promises.
* **Lesson 7:** Connecting Data from API to Display in the DOM

  * *Mini-Project 2: Complete* (replace fake data with real Pokémon API responses).

**Fri**

* **Lesson 8:** Secrets and the Weather API

  * Learn about API keys, secrets, and environment handling.
  * *Extension:* Add a Weather component to Mini-Project 2 for a multi-API experience.

This pacing:

* **Day 1**: Foundation (forms + query params).
* **Day 2**: API request intro (Postman + network tab).
* **Day 3–4**: Coding with objects, promises, and DOM updates.
* **Day 5**: Advanced API integration (secrets, multiple APIs).
