# 🧪 Lesson 5 — Postman Code Generation (Level 5)

**Tags:** `#lesson` `#level5` `#postman` `#javascript` `#scaling`
**Goal:** Scale your app to handle multiple cities by creating additional weather functions.

---

## Overview

Now that you have one city working, let's expand to multiple cities! This level teaches you how to scale your app by creating similar functions for different locations.

---

## Steps

### 6. Repeat for the other cities

For each new city:
* Create a new function (e.g., `fetchSeattleWeather`, `fetchNYCWeather`)
* Get coordinates from Postman
* Generate code and paste into the function
* Test in Console first
* Optional: Add buttons for each city

---

## City Coordinates Reference

* **New Orleans**: `latitude=29.95&longitude=-90.07`
* **Seattle**: `latitude=47.61&longitude=-122.33`
* **New York**: `latitude=40.71&longitude=-74.01`
* **Los Angeles**: `latitude=34.05&longitude=-118.24`
* **Chicago**: `latitude=41.88&longitude=-87.63`
* **Miami**: `latitude=25.76&longitude=-80.19`
* **Denver**: `latitude=39.74&longitude=-104.99`
* **Taipei**: `latitude=25.03&longitude=121.57`

---

## ✅ Check Your Work

- [ ] At least 2 additional city functions are created
- [ ] Each function uses correct coordinates from the reference
- [ ] Each function is tested in console and shows weather data
- [ ] Functions follow the same naming pattern (fetch[City]Weather)
- [ ] Optional: Buttons are added for each city
