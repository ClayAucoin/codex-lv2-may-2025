# Tools & Environments

### VS Code (Visual Studio Code)
The primary IDE for writing and managing code.
* **Settings:** Configured in `settings.json`.
* `editor.formatOnSave: true` → auto-format on save.
* `files.autoSave: "afterDelay"` → auto-save changes.
* **Color Theme:** Customizable (e.g., “Default Dark”, “Abyss”).
* **Auto-completion:** Suggests code as you type (CSS, JS).
* **Automatic Formatting:** Triggered with `Alt-Shift-F`.
* **Known Bugs:** Path navigation issues if filenames change case; restarting fixes some issues.
* **Boilerplate:** HTML starter generated by typing `!` + Tab.
* **Explorer:** Sidebar for browsing project files.
→ Related: [Boilerplate](#boilerplate), [HTML](#html), [CSS](#css)

### Terminal (Shell)
Command-line interface integrated in VS Code for running [Git](../week1-git/GLOSSARY.md#git) and [Node.js](#nodejs).
→ Related: [Mkdir](../week1-git/GLOSSARY.md#mkdir-make-directory)

### Git
A **version control system**.
* `git init` → initialize repo.
* `git add` → stage changes.
* `git commit -m "message"` → save snapshot.
* `git push` → send changes to remote.
* **Workflow:** `git add` → `git commit` → `git push`.
* **Repositories:** Local + remote storage for projects.
→ Related: [GitHub](#github), [Commit (Git)](../week1-git/GLOSSARY.md#commit-git), [Diff (Git)](../week1-git/GLOSSARY.md#diff-git)

### GitHub
Platform for hosting repos and collaborating.
* **Username:** Needed for surveys.
* **URLs:** Web addresses of repos submitted weekly.
→ Related: [Repositories](../week1-git/GLOSSARY.md#repositories-repos)

### Node.js
A JavaScript runtime to run JS outside browsers.
* Errors like `"node is not defined"` indicate installation/configuration issues.
→ Related: [JavaScript](#javascript)

### OneDrive
Cloud storage service.
* May cause conflicts with Git due to auto-sync.
