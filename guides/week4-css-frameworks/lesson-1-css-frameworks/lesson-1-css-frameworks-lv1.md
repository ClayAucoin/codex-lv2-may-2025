## Lesson: Introduction to Classless CSS

### 🎯 Objective

Learn about classless CSS frameworks and how they automatically style HTML elements without requiring classes.

### 📚 Quick Reference
See the [CSS Snippets](./lesson-1-css-snippets.md) for HTML templates and examples.

---

## ✅ Step 1: Understanding Classless CSS

Classless CSS frameworks automatically style your HTML elements without you needing to add any CSS classes. They work by targeting HTML tags directly.

### A. Test Your First Classless Framework

Replace the content in your `index.html` file with this code:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Classless CSS Test</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/98.css" />
</head>
<body>
  <h1>Welcome to the Retro Web</h1>
  <p>This page is using a classless CSS framework. No classes required!</p>
  <ul>
    <li>Fast styling</li>
    <li>No setup needed</li>
    <li>Fun themes</li>
  </ul>
  <button>Click Me!</button>
</body>
</html>
```

### B. Open in Your Browser

Open `index.html` in your web browser and notice how the page now has a retro Windows 98 style!

**🧪 Think About:**

* What changed in the appearance?
* What does the CSS file decide for you?
* How is this different from writing your own CSS?
