## Unit Overview: CSS Frameworks for Professional Web Design

### 🧭 Objective

In this unit, students will learn how CSS frameworks can help build beautiful websites quickly, starting from classless styles and progressing to full UI components. Students will explore different frameworks, customize themes, and build responsive layouts to understand the power and flexibility of modern CSS frameworks.

---

### 🎯 Learning Goals

* Understand the difference between classless and utility-based CSS frameworks
* Set up and configure different CSS frameworks in HTML projects
* Explore and compare various CSS themes and frameworks
* Customize framework styles and add responsive images
* Research and implement additional CSS libraries
* Build a theme comparison project to showcase different frameworks

---

### 📚 Lesson List

0. **[Project Setup](./lesson-1-css-frameworks-lv0.md)** *(Setup)*  
   Create your project folder, initialize Git, and set up the basic HTML structure for CSS framework testing.

1. **[Classless CSS Introduction](./lesson-1-css-frameworks-lv1.md)** *(Foundation)*  
   Learn about classless CSS frameworks and how they automatically style HTML elements without requiring classes.

2. **[Theme Exploration](./lesson-1-css-frameworks-lv2.md)** *(Exploration)*  
   Try different CSS themes and frameworks, comparing their visual styles and understanding their unique characteristics.

3. **[Customization and Images](./lesson-1-css-frameworks-lv3.md)** *(Customization)*  
   Add custom images and explore how different frameworks handle responsive design and image styling.

4. **[Advanced Framework Research](./lesson-1-css-frameworks-lv4.md)** *(Research)*  
   Research additional CSS libraries, read documentation, and implement components from different frameworks.

5. **[Theme Garden Project](./lesson-1-css-frameworks-lv5.md)** *(Project)*  
   Create a comprehensive theme comparison project showcasing multiple frameworks with rankings and explanations.

---

### ✅ Project Outcome

By the end of this unit, students will:

* Have a complete understanding of CSS framework types and use cases
* Be able to quickly implement and switch between different CSS themes
* Understand responsive design principles through framework implementation
* Have experience researching and implementing CSS libraries
* Create a portfolio piece demonstrating framework knowledge
* Be comfortable reading and following CSS framework documentation

---

### 🛠️ Prerequisites

* Basic HTML knowledge
* Understanding of CSS fundamentals
* Git and GitHub workflow experience
* VSCode or similar code editor
* Web browser for testing and viewing results

---

### 🎨 Framework Types Covered

* **Classless CSS**: 98.css, PS2.css, Water.css, Tufte.css
* **Utility Frameworks**: Picnic CSS
* **Component Libraries**: PaperCSS, Chota, Bootstrap
* **Custom Themes**: Student-created variations

---

### 📁 Project Structure

Students will create:
* `index.html` - Main testing page
* `retro.html`, `water.html`, `tufte.html` - Theme variations
* `theme-garden.html` - Framework comparison showcase
* `style.css` - Custom modifications
* `README.md` - Project documentation
