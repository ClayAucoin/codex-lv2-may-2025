## Lesson: Create Your Theme Garden Project

### 🎯 Objective

Create a comprehensive theme comparison project showcasing multiple frameworks with rankings and explanations.

### 📚 Quick Reference
See the [CSS Snippets](./lesson-1-css-snippets.md) for HTML templates and examples.

---

## ✅ Step 5: Theme Garden Project

This is your final project! You'll create a showcase of all the CSS frameworks you've explored, demonstrating your understanding and providing a portfolio piece.

### A. Create Theme Variation Pages

Make several copies of your main page, each with a different CSS framework:

#### 1. Create `retro.html` (98.css)
- Use the 98.css framework for a nostalgic Windows 98 look
- Include your image and content
- Add descriptive text about the retro aesthetic, Windows 98 nostalgia, and fun, playful design

#### 2. Create `water.html` (Water.css)
- Use the Water.css framework for a clean, modern aesthetic
- Include your image and content
- Add descriptive text about minimal design, excellent readability, and professional appearance

#### 3. Create `tufte.html` (Tufte.css)
- Use the Tufte.css framework for an academic, typography-focused design
- Include your image and content
- Add descriptive text about excellent typography, academic style, and content-focused design

### B. Create Your Theme Garden Showcase

Create `theme-garden.html` - your main showcase page. Link to the other files from this one.

### C. Final Steps

1. **Test all your pages** - Make sure each theme page works correctly
2. **Customize your content** - Add your own thoughts and ratings
3. **Commit your work** - Save all your progress to Git
4. **Share your project** - Push to GitHub and show off your theme garden!
