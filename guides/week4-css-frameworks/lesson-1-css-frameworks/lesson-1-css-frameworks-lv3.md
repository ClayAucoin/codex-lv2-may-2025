Add custom images and explore how different frameworks handle responsive design and image styling.

### 📚 Quick Reference

## ✅ Step 3: Adding Images and Customization

Now let's add images to your page and see how different CSS frameworks handle them. This will help you understand responsive design principles.

### A. Add an Image to Your Page

Add this image tag at the top of your page content (after the `<h1>`):

```html
<img src="https://images.pexels.com/photos/1108099/pexels-photo-1108099.jpeg" alt="Beautiful landscape">
```

### B. Test with Different Frameworks

Try your page with different CSS frameworks and observe how they handle the image:

1. **98.css** - How does the retro theme style the image?
2. **Water.css** - Notice the clean, modern image treatment
3. **Tufte.css** - See how the academic theme handles images

**🧪 Observe and Document:**
* How does each framework style images?
* Are the images responsive (do they resize with the window)?
* What differences do you notice in image presentation?

### C. Try Your Own Images

Visit [Pexels](https://www.pexels.com) and find images you like:
* Download them to your project folder
* Update the `src` attribute to use your local images
* Test how different frameworks handle various image types
