### ✅ Prompt for Generating Group Website Project Lessons on GitHub Pages

> Create a full unit outline for a collaborative GitHub Pages website project designed for 2–4 students per group.
>
> The unit should:\n>
>
> * Have a clear **Objective** section at the top explaining the project goals
> * Include a section titled **Group Collaboration Goals**
> * Provide a numbered **Lesson Outline** with 10–15 steps
> * Mark each step as either **(Group)** or **(Individual)**
> * Use clear, student-friendly language and list any tools or features used (e.g., branches, pull requests, issues)\n>
> * Focus on realistic classroom use with GitHub’s web interface only (no command line)\n>
> * End with a **Project Outcome** section listing what students will achieve by the end of the unit\n>
>
> Optional: Include example tasks such as simple HTML edits, linking a CSS file, or assigning issues.\n>
> Format the entire response as a markdown document.\n>
> Example lesson topics include:\n> - Creating a repository as a group\n> - Adding collaborators\n> - Creating a shared homepage\n> - Assigning group members pages to work on\n> - Using GitHub issues to manage work\n> - Merging pull requests into the main branch\n> - Adding shared CSS and linking it
